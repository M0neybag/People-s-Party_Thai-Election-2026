# พรรคประชาชน 2569 · Dashboard ผลเลือกตั้ง สส.

Dashboard แบบ interactive (D3.js) หน้า 1 มี 5 โหมด ได้แก่ สส.เขต / สส.บัญชีรายชื่อ / สส.เขต + บัญชีรายชื่อ / ความห่างคะแนน / ระดับโอกาส และเปรียบเทียบกับปี 66 ได้

## โครงสร้างไฟล์

```
index.html            หน้า dashboard (เวอร์ชันใหม่)
index-v1.html         ← เวอร์ชันเดิมของทีม (เปลี่ยนชื่อจาก index.html เดิม ดูหัวข้อด้านล่าง)
css/style.css         หน้าตา สี และขนาด
js/app.js             โค้ดทั้งหมด (ค่าที่ปรับได้อยู่ช่วงบนสุดของไฟล์)
data/districts.json   ผลรายเขต 400 เขต ทั้งปี 69 และปี 66
data/layout.json      พิกัดช่องบนแผนที่ (ทีมแก้เองได้)
data/national.json    ผลรวมทั้งประเทศ ปี 66 และ 69
data/logos.json       โลโก้พรรค
```

## เก็บ index.html เดิมไว้ใช้คู่กัน

ให้รันคำสั่งในโฟลเดอร์ repo

```bash
git tag v1-original                      # (แนะนำ) ทำ snapshot ของเวอร์ชันเดิมไว้ก่อน
git mv index.html index-v1.html          # เปลี่ยนชื่อไฟล์เดิม
# คัดลอกไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวางใน repo
git add .
git commit -m "เพิ่ม dashboard เวอร์ชันใหม่ เก็บเวอร์ชันเดิมเป็น index-v1.html"
git push
```

เมื่อเปิดผ่าน GitHub Pages จะเข้าได้สองที่

- `https://<username>.github.io/<repo>/` แสดงเวอร์ชันใหม่
- `https://<username>.github.io/<repo>/index-v1.html` แสดงเวอร์ชันเดิม

หน้าใหม่จะแสดงลิงก์ "เวอร์ชันเดิม ↗" ใต้ชื่อโดยอัตโนมัติ ถ้ามีไฟล์ `index-v1.html` อยู่จริง ถ้าต้องการใช้ชื่อไฟล์อื่น ให้แก้ `OLD_VERSION_URL` ในบรรทัดแรกๆ ของ `js/app.js`

> **ควรตรวจก่อน:** ถ้า index.html เดิมเรียกไฟล์ชื่อเดียวกับของใหม่ เช่น `css/style.css` หรือ `js/app.js` ไฟล์ใหม่จะทับไฟล์เดิม ให้เปลี่ยนชื่อโฟลเดอร์ของฝั่งใดฝั่งหนึ่งก่อน
>
> ถ้าต้องการย้อนกลับไปเวอร์ชันเดิมทั้ง repo ให้ใช้ `git checkout v1-original`

## เปิดดูในเครื่อง

หน้าเว็บอ่านข้อมูลจากไฟล์ `.json` เบราว์เซอร์จึงไม่ยอมโหลดถ้าดับเบิลคลิกเปิด `index.html` ตรงๆ ให้เปิดผ่านเว็บเซิร์ฟเวอร์แบบใดแบบหนึ่ง

```bash
python -m http.server 8000     # แล้วเปิด http://localhost:8000
```

หรือใช้ส่วนขยาย **Live Server** ใน VS Code

## เปิด GitHub Pages

ไปที่ Settings → Pages → Source แล้วเลือก "Deploy from a branch" จากนั้นเลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save รอประมาณ 1–2 นาที

## แก้พิกัดแผนที่ (data/layout.json)

ไฟล์นี้เก็บข้อมูลจังหวัดละ 1 บรรทัด เช่น

```json
"12": {"name": "นนทบุรี", "lx": 12.375, "ly": 29.148, "tiles": [[11.025, 29.6], [12.025, 29.6], ...]}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `"12"` | รหัสจังหวัด (ต้องตรงกับ `pc` ใน districts.json) |
| `name` | ชื่อที่แสดงบนแผนที่ |
| `lx`, `ly` | ตำแหน่งชื่อจังหวัด |
| `tiles` | ตำแหน่งของแต่ละเขต ตัวแรกคือเขต 1 ตัวที่สองคือเขต 2 ตามลำดับ |
| `S` (บนสุดของไฟล์) | ความเอียงของช่องสี่เหลี่ยมด้านขนาน (0.3) |

- หน่วยเป็น "ช่อง" โดย 1 ช่องกว้าง 1 หน่วย
- ค่า x มากขึ้นช่องจะไปทางขวา ค่า y มากขึ้นช่องจะลงล่าง
- ถ้าจะย้ายทั้งจังหวัด ให้บวกหรือลบค่า x หรือ y ของทุกช่องใน `tiles` และ `lx`/`ly` ด้วยค่าเดียวกัน
- จำนวนคู่ใน `tiles` ต้องเท่ากับจำนวนเขตของจังหวัดนั้น ถ้าไม่เท่า ให้เปิด Console ของเบราว์เซอร์ (F12) จะมีคำเตือน `layout.json: ...` บอกว่าขาดหรือเกินเขตใด
- แผนที่จะย่อขยายให้พอดีกรอบเองทุกครั้ง จึงไม่ต้องห่วงขอบ

## ปรับค่าอื่นๆ (บนสุดของ js/app.js)

- `PC` สีของแต่ละพรรค
- `GB` ช่วงสีของโหมดความห่างคะแนน
- `TT` ชื่อและสีของระดับโอกาส ส่วนเกณฑ์อยู่ในฟังก์ชัน `prep()`
- `REGIONS` รายการภาคใน dropdown
- `OLD_VERSION_URL` ชื่อไฟล์เวอร์ชันเดิม

## เพิ่มหรือเปลี่ยนโลโก้พรรค

`data/logos.json` เป็นแมป `"ชื่อพรรค": "data:image/png;base64,..."` ถ้าพรรคใดยังไม่มีโลโก้ จะแสดงตัวอักษรแรกในวงกลมแทน
ตอนนี้ยังไม่มีโลโก้ของ ชาติไทยพัฒนา ชาติพัฒนากล้า และเพื่อไทรวมพลัง ถ้าจะเพิ่ม ให้แปลงรูป PNG สี่เหลี่ยมจัตุรัสเป็น base64 แล้วใส่เป็นรายการใหม่

## หมายเหตุข้อมูล

- ระยะห่าง สส.เขต = (คะแนนพรรคประชาชน − คู่แข่งที่ใกล้ที่สุด) ÷ บัตรดี × 100
- ระยะห่างบัญชีรายชื่อ = แบบเดียวกัน แต่ใช้คะแนนบัญชีรายชื่อในเขต ÷ คะแนนบัญชีรายชื่อรวมของเขต
- "พลิกได้" หมายถึง แพ้ สส.เขต แต่คะแนนบัญชีรายชื่อของพรรคในเขตนั้นมากกว่าคะแนนของผู้ชนะเขต
- ปี 66 นับพรรคก้าวไกลเป็นพรรคเดียวกับประชาชน แต่แสดงชื่อว่า "ก้าวไกล"
- มี 2 เขตที่ไม่มีข้อมูลปี 66 คือ ปทุมธานี เขต 8 และสมุทรสาคร เขต 4 ส่วนเขตที่ผู้มีสิทธิ์ต่างจากปี 66 เกิน 5% จะมีคำเตือนว่าอาจถูกแบ่งเขตใหม่
- ที่นั่งบัญชีรายชื่อคำนวณด้วยวิธีเศษเหลือมากที่สุดจาก 100 ที่นั่ง
