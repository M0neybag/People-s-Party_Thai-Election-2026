# พรรคประชาชน 2569 · Dashboard ผลเลือกตั้ง สส.

Dashboard แบบ interactive สำหรับวิเคราะห์ผลการเลือกตั้ง สส. ปี 2569 ทั้ง 400 เขต จากมุมมองของพรรคประชาชน สร้างด้วย [D3.js](https://d3js.org/) v7 เป็นเว็บแบบ static ไม่ต้องมี backend

🔗 **เว็บไซต์:** https://thai-election-2026.vercel.app

## ฟีเจอร์

### 5 โหมด

| โหมด | แผนที่แสดง | กราฟด้านขวา |
|---|---|---|
| **สส.เขต** | พรรคผู้ชนะแต่ละเขต | การ์ดสรุป + กราฟ overview + detail ระยะห่างคะแนน |
| **สส.บัญชีรายชื่อ** | พรรคที่ได้คะแนนบัญชีรายชื่อสูงสุดในเขต | การ์ดสรุป + กราฟ overview + detail |
| **สส.เขต + บัญชีรายชื่อ** | ช่องแบ่งครึ่ง 2 สี (บนซ้าย = เขต, ล่างขวา = บัญชีฯ) | กราฟ overview + detail 2 กราฟ |
| **ระดับโอกาส** | ระดับโอกาส 5 ระดับ | Scatter plot (ลากกรอบเลือกกลุ่มเขตได้) + ตาราง |
| **ข้อมูลบ้านใหญ่** | 200 เขตที่มีตระกูลบ้านใหญ่ลงสมัคร | สรุป + แยกตามภาค + แยกตามพรรค + % ที่พรรคประชาชนชนะ |

### ตัวกรองและการโต้ตอบ

- **เลือกภาค:** dropdown ด้านบน แผนที่ซูมไปที่ภาคนั้น
- **ชิปกรอง:** ทั้งหมด / สูสี ±5% / เขต-พรรค สวนทาง เขตที่ไม่ตรงเงื่อนไขจะจางลง ไม่หายไป
- **เปรียบเทียบปี 66:** ใช้ได้ในโหมด สส.เขต และ บัญชีรายชื่อ แสดงผลปี 66 คู่กับปี 69
- **บ้านใหญ่ชนะ:** checkbox บนแผนที่ แสดงเฉพาะเขตที่ผู้ชนะเป็นบ้านใหญ่
- **Legend:** คลิกเพื่อกรองพรรคหรือระดับ ในโหมด สส.เขต และบัญชีฯ สลับ "สีตามพรรค / สีตามระยะห่าง" ได้
- **แผนที่:** ซูมและเลื่อนได้ (ซูมสูงสุด 4 เท่า) ชี้ช่องเพื่อดู tooltip คลิกเพื่อเปิดรายละเอียดเขต
- **กราฟ overview + detail:**
  - กรอบสีส้มบนกราฟเลือกช่วงเขตที่แสดงในรายการด้านล่าง ลากหรือปรับขนาดกรอบได้
  - หมุนล้อเมาส์จนสุดรายการ กรอบจะเลื่อนตาม
  - ชี้เขตบนแผนที่หรือในรายการ ลูกศรดำจะชี้ตำแหน่งเขตนั้นบนกราฟ (โหมด เขต + บัญชีฯ ขึ้นทั้ง 2 กราฟ)
  - เรียง "ตามระยะห่าง" หรือ "แยกภาค" ได้
- **หน้ารายละเอียดเขต:**
  - ตารางผู้สมัครและพรรค คลิกหัวคอลัมน์เพื่อเรียงได้
  - แสดง 5 อันดับแรก กด "ดูเพิ่มเติม" เพื่อดูที่เหลือ
  - กราฟเทียบ สส.เขต กับบัญชีรายชื่อในเขต
  - สถิติบัตรเลือกตั้ง
- **หน้าบ้านใหญ่:** คลิกแท่งภาค แท่งพรรค หรือ legend เพื่อกรอง (link & brush) กด ✕ ที่ชิปเพื่อล้างตัวกรอง

```
data/layout.json      พิกัดช่องบนแผนที่ (ทีมแก้เองได้)

data/parties.json     สีและหมายเลขของแต่ละพรรค (พรรคละ 1 บรรทัด)
data/logos.json       โลโก้พรรคปี 69 (base64)
data/logos66.json     โลโก้พรรคปี 66 (base64)
```

- D3.js 7.9.0 จาก cdnjs
- ฟอนต์ IBM Plex Sans Thai จาก Google Fonts

## เปิดดูในเครื่อง

หน้าเว็บอ่านข้อมูลจากไฟล์ `.json` ถ้าดับเบิลคลิกเปิด `index.html` ตรงๆ จะขึ้นแถบแดง "โหลดข้อมูลไม่ได้" ต้องเปิดผ่านเว็บเซิร์ฟเวอร์แบบใดแบบหนึ่ง

**วิธีที่ 1: Python**

```bash
python -m http.server 8000
# แล้วเปิด http://localhost:8000
```

**วิธีที่ 2: VS Code**

ติดตั้งส่วนขยาย **Live Server** แล้วคลิกขวาที่ `index.html` → *Open with Live Server*

## อัปขึ้น GitHub / Vercel

1. คัดลอกไฟล์ทั้งหมดไปวางใน repo (ทับไฟล์เดิมได้)
2. commit แล้ว push
3. Vercel จะ deploy ใหม่ให้เองภายใน 1–2 นาที

```bash
git add .
git commit -m "อัปเดต dashboard"
git push
```

**ถ้าต้องการเก็บหน้าเดิมไว้** ให้เปลี่ยนชื่อ `index.html` เดิมเป็น `index-v1.html` ก่อนวางไฟล์ใหม่

```bash
git tag v1-original              # (แนะนำ) snapshot เวอร์ชันเดิมไว้ก่อน
git mv index.html index-v1.html
```

ชื่อไฟล์เวอร์ชันเดิมตั้งได้ที่ `OLD_VERSION_URL` ท้ายไฟล์ `js/app.js` ถ้าต้องการย้อนทั้ง repo กลับไปเวอร์ชันเดิม ใช้ `git checkout v1-original`

## การแก้ไขที่ทำบ่อย

### แก้สีพรรค: `data/parties.json`

```json
"ประชาชน": {"n": 46, "c": "#FF6411"},
```

- `c` คือสีของพรรค ถ้าใส่ `#D3D3D3` จะถือว่าไม่มีสี และใช้สีเทาชนวน `#5E6573` แทน
- `n` คือหมายเลขพรรค

### แก้พิกัดแผนที่: `data/layout.json`

```json
"S": 0.3,
"prov": {
  "12": {"name": "นนทบุรี", "lx": 12.375, "ly": 29.148, "tiles": [[11.025, 29.6], [12.025, 29.6], ...]},
```

| ฟิลด์ | ความหมาย |
|---|---|
| `S` | ความเอียงของช่องสี่เหลี่ยมด้านขนาน |
| `"12"` | รหัสจังหวัด ต้องตรงกับ `pc` ใน districts.json |
| `name` | ชื่อที่แสดงบนแผนที่ |
| `lx`, `ly` | ตำแหน่งชื่อจังหวัด |
| `tiles` | ตำแหน่งของแต่ละเขต ตัวแรกคือเขต 1 ตัวที่สองคือเขต 2 ตามลำดับ |

- หน่วยเป็น "ช่อง" 1 ช่องกว้าง 1 หน่วย ค่า x มากขึ้นช่องไปทางขวา ค่า y มากขึ้นช่องลงล่าง
- ถ้าจะย้ายทั้งจังหวัด ให้บวกหรือลบค่า x หรือ y ของทุกช่องใน `tiles` และ `lx`/`ly` ด้วยค่าเดียวกัน
- จำนวนคู่ใน `tiles` ต้องเท่ากับจำนวนเขตของจังหวัดนั้น
- แผนที่ย่อขยายให้พอดีกรอบเอง ไม่ต้องห่วงขอบ

### ค่าที่ปรับได้ (บนสุดของ `js/app.js`)

| ค่า | ความหมาย |
|---|---|
| `MAIN5` | 5 พรรคที่แยกสีใน legend (ที่เหลือรวมเป็น "พรรคอื่น") |
| `OTHER`, `NODATA` | สีพรรคอื่น / สีช่องที่ไม่มีข้อมูล |
| `REGIONS` | รายการภาคใน dropdown |
| `MODES` | ชื่อและลำดับปุ่มโหมด |
| `GB` | ช่วงสีของ "สีตามระยะห่าง" |
| `TT` | ชื่อและสีของระดับโอกาส |
| `TK` | ลำดับระดับโอกาสใน legend |

### เกณฑ์ระดับโอกาส

อยู่ในฟังก์ชัน `prep()` ใน `js/app.js` (ค้นคำว่า `d.tier =`) ให้ m = ระยะห่าง สส.เขต (ค่าสัมบูรณ์)

| ผล สส.เขต | เงื่อนไข | ระดับ |
|---|---|---|
| แพ้ | m ≤ 5% | **พลิกได้** |
| แพ้ | 5% < m < 30% และชนะบัญชีรายชื่อในเขต | **ดันผู้สมัคร** |
| แพ้ | m ≥ 30% หรือไม่ชนะบัญชีรายชื่อในเขต | **ปรับแผนใหม่** |
| ชนะ | m > 5% และชนะบัญชีรายชื่อในเขต | **ฐานเสียง** |
| ชนะ | นอกเหนือจากนั้น | **รักษาฐานเสียง** |

## รองรับอุปกรณ์และเบราว์เซอร์

| ขนาดจอ | การจัดหน้า |
|---|---|
| กว้าง ≥ 1280px | แผนที่ซ้าย กราฟขวา |
| 1024–1279px (เช่น iPad แนวนอน) | 2 คอลัมน์เท่ากัน |

- **จอสัมผัส:** แตะช่องเพื่อเปิดรายละเอียดเขต ส่วน tooltip และลูกศรดำต้องใช้เมาส์ชี้ (ยังไม่รองรับการกดค้าง)

## หมายเหตุข้อมูล

- **ระยะห่าง สส.เขต** = (คะแนนพรรคประชาชน − คู่แข่งที่ใกล้ที่สุด) ÷ บัตรดี × 100
  - ค่าบวกแปลว่าพรรคประชาชนชนะ ค่าลบแปลว่าแพ้
- **ระยะห่างบัญชีรายชื่อ** = สูตรเดียวกัน แต่ใช้คะแนนบัญชีรายชื่อในเขต ÷ คะแนนบัญชีรายชื่อรวมของเขต
- **สูสี ±5%** = ระยะห่างไม่เกิน 5% ทั้งฝั่งชนะและแพ้
- **บ้านใหญ่** = ผู้สมัครที่นามสกุลตรงกับรายชื่อตระกูลบ้านใหญ่ 225 ตระกูล (ช่องที่ 5 ของรายชื่อผู้สมัครใน `districts.json`)
  - จับคู่ด้วยนามสกุลเท่านั้น จึงอาจมีคนนามสกุลซ้ำที่ไม่ได้อยู่ในตระกูลนั้นจริง
- **ปี 66** นับพรรคก้าวไกลเป็นพรรคเดียวกับพรรคประชาชน แต่แสดงชื่อว่า "ก้าวไกล"
- **ปทุมธานี เขต 8 และสมุทรสาคร เขต 4** ไม่มีข้อมูลปี 66 ฝั่งปี 66 จะเว้นว่าง
- **ที่นั่งบัญชีรายชื่อ** คำนวณด้วยวิธีเศษเหลือมากที่สุด จาก 100 ที่นั่ง
