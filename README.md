## ฟีเจอร์

### 5 โหมด (ปุ่มด้านบน)

| โหมด | แผนที่แสดงอะไร | ด้านขวาแสดงอะไร |
|---|---|---|
| **สส.เขต** | พรรคที่ชนะแต่ละเขต | การ์ดสรุป + กราฟ overview + detail (ระยะห่างคะแนน) |
| **บัญชีรายชื่อ** | พรรคที่ได้คะแนนบัญชีรายชื่อสูงสุดในเขต | การ์ดสรุป + กราฟ overview + detail |
| **สส.เขต + บัญชีรายชื่อ** | ช่องแบ่งครึ่ง 2 สี (บนซ้าย = เขต, ล่างขวา = บัญชีรายชื่อ) | กราฟ overview + detail 2 กราฟ |
| **วางแผนพรรค** | ระดับโอกาส 5 ระดับ | Scatter plot (ลากกรอบเลือกกลุ่มเขตได้) + ตาราง |
| **ข้อมูลบ้านใหญ่** | 200 เขตที่มีตระกูลบ้านใหญ่ลงสมัคร | สรุป + แยกตามภาค + แยกตามพรรค + % ที่พรรคประชาชนชนะ |

### ตัวกรองและการโต้ตอบ

- **เลือกภาค** (dropdown) — แผนที่ซูมไปที่ภาคนั้น
- **ชิปกรอง** ทั้งหมด / สูสี ±5% / เขต-พรรค สวนทาง — เขตที่ไม่ตรงเงื่อนไขจะจางลง (ไม่หายไป)
- **เปรียบเทียบปี 66** — ใช้ได้ในโหมด สส.เขต และ บัญชีรายชื่อ
- **บ้านใหญ่ชนะ** (checkbox บนแผนที่) — แสดงเฉพาะเขตที่ผู้ชนะเป็นบ้านใหญ่
- **Legend** — คลิกเพื่อกรองพรรค/ระดับ · โหมด สส.เขต และ บัญชีรายชื่อ สลับ "สีตามพรรค / สีตามระยะห่าง" ได้
- **แผนที่** — ซูม/เลื่อนได้ (สูงสุด 4 เท่า) · ชี้ช่องเพื่อดู tooltip · คลิกเพื่อเปิดรายละเอียดเขต
- **กราฟ overview + detail**
  - กรอบสีส้มเลือกช่วงเขตที่แสดงในรายการด้านล่าง (ลาก/ปรับขนาดได้)
  - หมุนล้อเมาส์จนสุดรายการ → กรอบเลื่อนตาม
  - ชี้เขตบนแผนที่หรือในรายการ → ลูกศรดำชี้ตำแหน่งเขตนั้นบนกราฟ (โหมด เขต + บัญชีรายชื่อ ขึ้นทั้ง 2 กราฟ)
  - เรียง "ตามระยะห่าง" หรือ "แยกภาค"
- **หน้ารายละเอียดเขต** — ตารางผู้สมัคร/พรรค (คลิกหัวคอลัมน์เพื่อเรียง) · 5 อันดับแรก + "ดูเพิ่มเติม" · กราฟเทียบเขตกับบัญชีรายชื่อ · สถิติบัตร
- **หน้าบ้านใหญ่** — คลิกแท่งภาค/แท่งพรรค/legend เพื่อกรอง (link & brush) · กด ✕ ที่ชิปเพื่อล้าง

| ค่า | ความหมาย |

### เกณฑ์ระดับโอกาส

อยู่ในฟังก์ชัน `prep()` ของ `js/app.js` (ค้นหา `d.tier =`) · m = ระยะห่าง สส.เขต (ค่าสัมบูรณ์)

| ผล สส.เขต | เงื่อนไข | ระดับ |
|---|---|---|
| แพ้ | m ≤ 5% | **พลิกได้** |
| แพ้ | 5% < m < 30% และชนะบัญชีรายชื่อในเขต | **ดันผู้สมัคร** |
| แพ้ | m ≥ 30% หรือไม่ชนะบัญชีรายชื่อในเขต | **ปรับแผนใหม่** |
| ชนะ | m > 5% และชนะบัญชีรายชื่อในเขต | **ฐานเสียง** |
| ชนะ | นอกเหนือจากนั้น | **รักษาฐานเสียง** |

### พิกัดแผนที่ (`data/layout.json`)

```json
"S": 0.3,
"prov": {
  "12": {"name": "นนทบุรี", "lx": 12.375, "ly": 29.148, "tiles": [[11.025, 29.6], [12.025, 29.6], ...]},
```

| ฟิลด์ | ความหมาย |
|---|---|
| `S` | ความเอียงของช่องสี่เหลี่ยมด้านขนาน |
| `"12"` | รหัสจังหวัด (ต้องตรงกับ `pc` ใน districts.json) |
| `name` | ชื่อที่แสดงบนแผนที่ |
| `lx`, `ly` | ตำแหน่งชื่อจังหวัด |
| `tiles` | ตำแหน่งแต่ละเขต ตัวแรก = เขต 1, ตัวที่สอง = เขต 2 … |

- หน่วยเป็น "ช่อง" (1 ช่อง = 1 หน่วย) · x มากขึ้น = ขวา · y มากขึ้น = ลง
- ย้ายทั้งจังหวัด: บวก/ลบ x หรือ y ของทุกช่องใน `tiles` และ `lx`/`ly` ด้วยค่าเดียวกัน
- จำนวนคู่ใน `tiles` ต้องเท่ากับจำนวนเขตของจังหวัดนั้น
- แผนที่ย่อขยายให้พอดีกรอบเอง ไม่ต้องห่วงขอบ

## Animation

อยู่ **ท้ายไฟล์** `js/app.js` (ค้นหา `animation ตอนเปลี่ยนโหมด`) และท้ายไฟล์ `css/style.css`

- ปุ่มโหมด: แถบขาวเลื่อนจากปุ่มเดิมไปปุ่มใหม่
- เปลี่ยนโหมด: กล่องด้านขวา การ์ดสรุป legend ค่อยๆ ปรากฏ
- เปลี่ยนโหมด / กดตัวกรอง: ช่องแผนที่ แท่งกราฟ แถวรายการ จุด scatter ค่อยๆ เปลี่ยนสีและความจาง
- ปิดเองอัตโนมัติถ้าเครื่องผู้ใช้ตั้ง "ลดการเคลื่อนไหว" (Reduce motion)

| อยากปรับ | ค้นหา |
|---|---|
| ความเร็วสี/ความจาง (มิลลิวินาที) | `A_DUR` ใน `app.js` |
| ความเร็วแถบปุ่มโหมดและการจางเข้า | `.26s` ใน `style.css` |
| หน้าตาปุ่มโหมดที่เลือก (สีพื้น เงา มุม) | `.seg .mode-pill` ใน `style.css` |

**ห้ามเปลี่ยน** ถ้ายังอยากให้ animation ทำงาน: ชื่อฟังก์ชัน `render`, `renderHeader` · id `#modes #filters #rk #legend #rescon #bigf` · คลาส `.kpis`
(ถ้าเปลี่ยน dashboard ยังใช้ได้ปกติ แค่ส่วนนั้นจะไม่มี animation)

## หมายเหตุข้อมูล

- **ระยะห่าง สส.เขต** = (คะแนนพรรคประชาชน − คู่แข่งที่ใกล้ที่สุด) ÷ บัตรดี × 100 — ค่าบวก = ชนะ, ค่าลบ = แพ้
- **ระยะห่างบัญชีรายชื่อ** = แบบเดียวกัน แต่ใช้คะแนนบัญชีรายชื่อในเขต ÷ คะแนนบัญชีรายชื่อรวมของเขต
- **สูสี ±5%** = ระยะห่างไม่เกิน 5% ทั้งฝั่งชนะและแพ้
- **บ้านใหญ่** = ผู้สมัครที่นามสกุลตรงกับรายชื่อตระกูลบ้านใหญ่ 225 ตระกูล (ช่องที่ 5 ของรายชื่อผู้สมัครใน `districts.json`) — จับคู่ด้วยนามสกุลเท่านั้น อาจมีคนนามสกุลซ้ำที่ไม่ได้อยู่ในตระกูลนั้นจริง
- **ปี 66** นับพรรคก้าวไกลเป็นพรรคเดียวกับพรรคประชาชน แต่แสดงชื่อว่า "ก้าวไกล"
- **ปทุมธานี เขต 8 และสมุทรสาคร เขต 4** ไม่มีข้อมูลปี 66 (ฝั่งปี 66 จะเว้นว่าง)
- **ที่นั่งบัญชีรายชื่อ** คำนวณด้วยวิธีเศษเหลือมากที่สุด จาก 100 ที่นั่ง
